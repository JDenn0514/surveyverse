# The Surveyverse: A Suite of Tools for Survey Research

The surveyverse is a collection of R packages for survey research,
sharing a common design philosophy, grammar, and data structures.
Loading
[`library(surveyverse)`](https://github.com/JDenn0514/surveyverse)
attaches all core surveyverse packages.

## Core packages

- [surveycore](https://jdenn0514.github.io/surveycore/) — Core survey
  design objects, S7 classes, and metadata infrastructure

- [surveytidy](https://jdenn0514.github.io/surveytidy/) — dplyr/tidyr
  verbs for survey objects

- [surveyweights](https://jdenn0514.github.io/surveyweights/) — Advanced
  weighting, raking, and calibration methods
